# 🎵 Music Genre Classification

**Interactive machine learning and deep learning project** built with **Python, NumPy, Pandas, Scikit-learn, and Jupyter Notebook**. This project focuses on automatically classifying music into different genres using **audio feature extraction, CNN, and CRNN models**.

---

## 🎯 About the Project

This project demonstrates how **Machine Learning and Deep Learning** can be applied to music genre classification.

The system processes audio data, extracts meaningful audio features, analyzes the resulting dataset, and trains classification models to identify the genre of a music track.

The project includes experiments with:

* Audio feature extraction
* Audio feature analysis
* Data preprocessing
* CNN-based classification
* CRNN-based classification
* Model training and evaluation
* Music genre prediction

## 🖥️ Project Features

### 🎧 Audio Feature Extraction

The project extracts useful characteristics from audio files that can help distinguish between different music genres.

These features can include:

* Spectral features
* Frequency-based features
* Rhythm-related features
* Mel-frequency features
* Other numerical audio representations

### 📊 Feature Analysis

The extracted audio features are analyzed to understand relationships and patterns between different music genres.

### 🤖 CNN Classification

A **Convolutional Neural Network (CNN)** is used to learn important patterns from audio representations and classify music into different genres.

### 🔄 CRNN Classification

A **Convolutional Recurrent Neural Network (CRNN)** combines CNN-based feature extraction with recurrent layers to capture both audio patterns and temporal information.

## 🔍 Music Genre Classification

Music Genre Classification is a classification task in which a machine learning or deep learning model predicts the genre of a music track based on its audio characteristics.

The model learns patterns from previously labeled music samples and uses those patterns to classify new audio samples.

Different genres can have distinctive characteristics related to:

* Tempo
* Rhythm
* Frequency distribution
* Timbre
* Energy
* Spectral properties
